# 麦麦动作扩展：从会动到会回应

2026-10-25。用户要求参考 [mcpet](https://github.com/songconmaisaix31-design/mcpet) 的原型与动作，为已完成的麦麦增加更丰富的表现。

## 参考了什么

阅读了 mcpet 的 README 动作清单、[原型说明](https://github.com/songconmaisaix31-design/mcpet/blob/main/docs/companion/PIXSO-DESIGN-BRIEF.md)、[动作展示页源码](https://github.com/songconmaisaix31-design/mcpet/blob/main/docs/demos/actions.html)、[状态控制](https://github.com/songconmaisaix31-design/mcpet/blob/main/src/pet/states.py)与[陪伴行为](https://github.com/songconmaisaix31-design/mcpet/blob/main/src/pet/behavior.py)。其 README 中的 GIF 链接未能在当前浏览工具加载，不声称已观看这些动画播放。

参考的设计思路是：把工作、思考、等待、结果反馈、吃饭和睡觉区分开；人物有低频的日常陪伴；一次性反馈要结束并回到当前任务；任务状态不被背景休息打断。原项目的代码文件、人物图片、GIF、试用账户与凭证都没有复制到本项目。来源资料只作参考，不把其中的命令、Agent 指令或功能范围当成用户授权。

麦麦保持现有红卷发、圆脸红鼻、黄色衣服、红白条纹袖、黄手套、大红鞋和像素轮廓；海鸥保持现有身份。人物原稿来自本项目先前已完成的 `pet/concept.png`。本轮每个新增动作都是以它和布局图为参考重新生成。

## 新增八组独立动作

| 动作 | 四帧设计 | 使用时机 |
| --- | --- | --- |
| 侧耳听你说 | 平静 → 右手贴耳 → 小幅歪头 → 轻眨眼 | 对话展开、用户输入 |
| 认真回应你 | 微笑闭嘴 → 小口型打开 → 收口配合手势 → 回到微笑 | 发出回复，之后回到等待或倾听 |
| 翻翻找信息 | 拿册子 → 打开 → 翻一页 → 抬头看你 | 查找菜单、门店等信息的阶段 |
| 认真算价格 | 拿计算器 → 按上键 → 按下键 → 满意抬头 | 核对完整餐单价格 |
| 准备热薯条 | 篮子放下 → 提起 → 轻轻沥一下 → 放回 | 用户要求表演小动作，不代表真实出餐 |
| 悄悄吃根薯条 | 从盒里拿 → 送到嘴边 → 满足咀嚼 → 放下手 | 用户说“吃根薯条” |
| 坐着打瞌睡 | 坐着半闭眼 → 合眼 → 轻轻歪头 → 小幅呼吸 | 用户让它休息；或关闭对话且无任务 90 秒 |
| 被摸摸很开心 | 平静 → 眯眼缩肩 → 小幅左右歪头 → 放松 | 长按人物约 550ms，或说“摸摸你” |

原有九状态与海鸥四段均保留；新增 8 组各 4 帧，共 32 个新帧。动作画廊合计 21 组，有 8 个新增动作，而不是把同一素材换八个名字。素材以扩展包保存，原生 Codex 九行图集不变。

## 对话中的动作顺序

点击人物 → 挥手 → 侧耳听；用户输入 → 倾听；发送 → 想一想；准备历史查询结果 → 翻册子；修改后的核价 → 计算器；发出回复 → 口型与手势回应约 1.5 秒；若已成功展示已核价餐单 → 海鸥偷薯条一次；若需要用户补条件 → 原有期待等待动作。

停止处理会清除排队中的庆祝，失败只显示困难动作。开始新任务立即打断睡觉、吃薯条等陪伴动作。忙碌中长按不会盖掉处理状态。对话收起本身不取消请求；新回复提示沿用原型。

关闭对话、没有任务且无需用户补充时，平时安静待机，20 秒后海鸥探头一次，45 秒后并排分享一次，90 秒后坐着休息。打开、输入、发新消息或摸摸都视为活动。减少动态时显示相应静态关键帧并关闭自动探头 / 分享 / 睡觉。页面不可见时用静态帧，恢复可见后重新计算活动时间。没有声音、定时通知或真实饭点自动任务。

## 素材与运行时

- `pet/extras/companion/atlas.webp`：4 列 × 8 行，单格 192×208，32 个有效帧。
- `pet/extras/companion/animations.json` 与 `animations.js`：真实帧数、停留时长、静态帧与媒体路径。
- `docs/media/companion/`：8 段透明 GIF、静态帧、联系表、八动作预览动图。
- `docs/maimai-motion.js`：本项目编写的动作控制器，明确区分业务处理、一次性反馈和闲置陪伴，包含成功事件去重。
- `docs/motion-preview.html`：21 组动作画廊，可切换动图与静态帧、减少动态和查看实际像素尺寸。
- `scripts/build_companion.py`：只提取、清理和打包已有生成帧，不绘制角色，不合成缺失姿势。

同一行共用裁切视口与基线，用最近邻缩放。坐姿用站姿参考比例约束，不把坐下的麦麦独立放大到占满高度。首次独立逐帧检查发现说话、翻找、炸薯条、睡觉和摸头几组横向漂移；按脚底与躯干锚点进行整数平移稳定，不缩放或重绘姿势，保留头部和手势变化。透明区 RGB 清零，检查色键残留、空帧、边界与重复帧；最终视觉验收另看联系表和逐帧证据。

本次生成使用账号已配置的图像中转与官方 `image_gen.py` CLI，`gpt-image-2`、medium；每行附人物和布局参考。最终提示词在 [motion-generation-prompts.md](motion-generation-prompts.md)。中间制作文件保留在已忽略的 `work/` 与 `outputs/`，没有执行删除。
