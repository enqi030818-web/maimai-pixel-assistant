回到麦麦对话原创动作扩展

麦麦，今天也有好多小动作。

听你说话、认真找信息、悄悄吃根薯条。点一个动作，看看它怎么回应。

新增陪伴动作

侧耳听你说

侧耳听，眨眨眼。你说的话，麦麦有在认真接。

动作展示不代表真实查询、制作餐品或下单。业务状态仍由聊天中的文字说明。

动作跟着交流走

点开麦麦 → 挥手；你输入 → 侧耳听；处理需求 → 想一想；找信息 → 翻册子；核对报价 → 算价格；发出回复 → 开口回应；等你补充 → 期待地等；成功 → 海鸥趁机顺薯条。

长按人物或发消息“摸摸你”有摸头回应。还可以说“休息一下”“吃根薯条”“一起吃薯条”“表演炸薯条”。关闭对话、无任务时，才会自动休息。
