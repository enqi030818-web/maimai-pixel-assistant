# 第一版范围

项目名暂用“麦麦 · 像素餐单助手”，宠物名“麦麦”。

初始交付形态是内置桌宠皮肤、业务 Skill 和真实麦当劳 MCP。宠物负责形象及宿主状态显示，Skill 负责查询、比较和确认单。初始范围只支持到店自取，不开发独立聊天窗口、模型服务、支付系统或养成游戏；2026-10-25 新增的悬浮对话产品方向见下文。

图像方向采用用户于 2026-10-24 补充的六张参考：红卷发、白色圆脸、红圆鼻、黄衣、红白条纹袖和大红鞋；约 2.25 头身，更可爱、更简洁，使用真正有块状边缘的像素风。用户参考中的字幕、表情包表情、气球、背景、品牌字样与飘浮装饰不进入桌宠资产。

所有动作以新版主形象为唯一身份基准。九行图集为 1536×1872，单元格 192×208；帧数分别为 6、8、8、4、5、8、6、6、6，剩余单元格透明。

点餐流程到确认单停止；未领取优惠不当作已拥有，不自动领券或下单。预算变化和替换后完整重新核价。只比较本轮候选，不承诺全局最低。

后续可扩展提醒、营养、成长和订单，但不计入本次已完成内容。2026-10-25 用户已授权公开发布 GitHub 并报名。

## 2026-10-25 点餐场景设计方向

用户明确希望角色进入点餐画面，接受先做自有概念界面、在设计中保留未来官方嵌入与自动点餐设想。视觉选择全像素游戏风；预算配餐、优惠活动、门店菜单三项全部纳入设计，语气为正常友好交流、偶尔玩梗。

新增可点击手机原型和 UI 交互契约，见 `mobile-ordering-ux.md`。这部分是新场景设计，不等同于已经将官方小程序、实时 AI 聊天、优惠账户或真实下单接通；原型中的历史和虚构样例均明确标注。

## 2026-10-25 对话方式修正（当前设计依据）

用户指出：应以和麦麦人物沟通为核心，通过对话完成查询；不能把主要操作放在点餐功能页面。已明确选择未来点餐页面中的悬浮麦麦、人物身旁展开对话并收起保留记录、文字加商品卡片、对话中选择和继续修改。套餐与单点商品图统一圆形。该方向取代此前“预算表单 + 三个功能页 + 聊天弹层”的界面结构。

当前原型改为背景点餐场景 + 可点击人物 + 贴身对话 + 消息内卡片。演示状态机可沿预算 → 追问门店 → 比较 → 选择 → 换杯 → 历史核价 → 确认单连续对话；提供停止、重试、旧餐单失效与减少动态。它不是正式自然语言模型，真实 AI、多用户会话和 MCP 后端仍需实现；圆形图片已按商品编码替换为 MCP 原图，缺图明确标注。官方点餐嵌入与自动点餐仍是后续目标。

## 2026-10-25 人物动作扩展

按用户要求参考 mcpet 的原型与动作分工，为原有麦麦重新生成八组共 32 帧独立动作，并接入当前悬浮对话原型。原有九状态与海鸥四段保留，动作画廊共 21 组；新增素材位于 `pet/extras/companion/`，不修改 Codex 原生九行图集。参考范围、事件映射、提示词和验收边界见 `motion-design.md`。本次没有新增提醒、养成、真实出餐或订单功能。
