# 麦麦与海鸥：搞薯条小剧场

用户确定的关系：海鸥偷偷顺薯条，麦麦一脸无奈。海鸥是惯犯，麦麦每次发现，却拿它没办法；偶尔主动分享，保留损友之间的陪伴感。

## 四段动作

| 片段 | 分镜 | 表情与节奏 |
| --- | --- | --- |
| 待机探头 | 麦麦抱薯条；海鸥从旁探头，一点点挪近；麦麦侧目，海鸥定住 | 慢靠近、短停顿，不连续打扰 |
| 完成偷吃 | 麦麦举起空着的手庆祝；海鸥叼走一根薯条，迈小碎步跑开；麦麦发现 | 先开心，后无奈；不是愤怒 |
| 抓包无奈 | 海鸥伸嘴抽薯条；麦麦低头；海鸥叼着薯条僵住；麦麦半眯眼塌肩 | 对视停半拍，靠眼神讲笑点 |
| 并排分享 | 麦麦坐下递一根；海鸥接过；两只并排坐着慢慢吃 | 这是主动分享，不能画成抢夺 |

## 美术约束

麦麦沿用已完成的红卷发、圆脸红鼻子、黄衣、条纹袖和红鞋。海鸥为矮胖白团子，灰翅、橙嘴橙脚、豆豆眼，约到站立麦麦腰部。薯条用粗金黄色像素块，保证 192×208 下能读懂。海鸥不是鸭子，不穿麦麦服装。每个片段固定角色尺寸和左右关系，避免角色突然变大、换脸或薯条穿模。

## 接入范围

Codex 原生宠物包使用固定九种状态和固定图集；没有经确认的自定义彩蛋或休息事件接口。本次扩展以独立透明动画素材、动作清单和本地交互预览交付，四段触发在预览中验证。原生九状态包继续保留。预览中的任务完成按钮是演示事件，不代表已接收到 Codex 的真实完成事件。

低干扰原则：普通待机沿用原版；待机彩蛋隔一段时间出现一次；完成片段每个任务最多一次；休息由用户主动触发；减少动态效果时显示静态关键帧。

## 已实现的素材与预览

- 待机探头 4 帧、完成偷吃 8 帧、抓包无奈 4 帧、并排分享 4 帧，共 20 帧。
- `pet/extras/seagull/atlas.webp`：1536×832，8 列 4 行，格子为 192×208；12 个未使用格完全透明。这是扩展格式，不替换 Codex 原生 8×9 图集。
- 同目录的 `animations.json` 保存顺序、逐帧时长、静态关键帧与单次播放标记；`animations.js` 是相同数据的本地页面入口，避免双击 HTML 时依赖 fetch。
- `docs/media/seagull/` 提供四段 GIF、静态关键帧、联系表和合并预览。GIF 循环仅便于审阅，交互预览按一次播放，停在结尾。
- `docs/seagull-preview.html` 提供选择、重播、暂停、原始尺寸、减少动态效果与可选自动探头。默认不自动播放彩蛋；开启后每 45–60 秒触发一次，播完返回普通待机。

完成段的跑动限制在格内，海鸥没有跑出画面；其中两帧麦麦也跟着抬腿，形成短暂追赶感。原版九状态文件保持一致。

## 预览事件接口

页面加载完成后，`window.maimaiSeagull` 暴露以下本地接口，供未来宿主适配层调用：

```javascript
window.maimaiSeagull.play('peek');       // peek / celebrate / caught / share
window.maimaiSeagull.taskComplete('任务唯一标识'); // 同一标识不会反复播放
window.maimaiSeagull.rest();             // 主动休息，播放并排分享
window.maimaiSeagull.idle();             // 恢复普通待机
```

这些接口只连接当前预览，不查询或操作真实任务。用户切换片段会中止旧片段；隐藏页面会停止计时和逐帧回调；减少动态效果时显示关键静态帧，不自动探头。去重缓存保留最近 128 个完成事件标识。

## 界面方向与验证

预览用薯条黄 `#ffcf3b`、番茄红 `#ca323b`、纸袋白 `#fff9e9`、深红棕 `#552d32` 与浅海蓝 `#dbeaf0`。字体采用本机微软雅黑／苹方，动画舞台与四项动作清单并列，小屏改为上下排列；强调实际角色画面，不添加与角色争抢注意力的装饰动效。

`node --test tests/test_seagull_preview.cjs` 验证片段切换取消旧动画、完成事件去重、减少动态效果、隐藏页面暂停和自动彩蛋的间隔及回归待机。素材另做透明度、空格、边界和独立视觉检查。当前自动化环境无可用浏览器，尚未完成真实浏览器中的布局与点击验收。
